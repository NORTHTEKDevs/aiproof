# AIP015: unhandled-placeholder

**Category:** Behavior  
**Severity:** Warning

Detects unresolved placeholders in the prompt that indicate incomplete or placeholder text.

## Markers

- `TODO` (uppercase)
- `FIXME` (uppercase)
- `XXX` (uppercase)
- `PLACEHOLDER` (uppercase)
- `...TBD` (case-insensitive for "TBD", leading dots literal)

## Example

**Bad:**
```
TODO: write the system prompt.
FIXME: tune the model temperature.
```

## Rationale

Placeholders left in production prompts cause unexpected model behavior and may expose internal development notes.
